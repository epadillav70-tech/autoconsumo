# AUTOCONSUMO

Autoconsumo es una aplicación de directorio multi-categoría para negocios, profesionistas, artesanos y agricultores.

Estructura del repositorio:
- apps/api: Backend (NestJS + Prisma)
- apps/web: Frontend Web (Next.js)
- apps/mobile: Aplicación móvil (React Native)
- infra: Helm charts y scripts de despliegue

Cómo usar:
1. Descomprimir el ZIP.
2. Seguir los READMEs por carpeta para inicializar cada aplicación.
